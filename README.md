## 🌟 Key Features

- **Interactive Information Cards**: Display custom heading text, descriptive body copy, and dynamic feature highlights on your SAC canvas.
- **Dedicated Builder & Styling Panels**: Seamlessly configure data properties in the Builder Panel and tailor visual styles in the Styling Panel.
- **Dynamic SAP Horizon Theme Sync**: Automatically matches SAP Analytics Cloud light and dark themes in real time without custom CSS.
- **Rich Typography & Visual Customization**: Personalize font sizing, font weight, text colors, and component visibility directly from the design panel.
- **Configuration Presets**: Export and import complete widget settings with one click to quickly replicate configurations across stories and tenants.

## 🚀 Installation

1. **Download** the [`Sample.json`](https://sample.rohitchouhan.com/download) from the link above or your GitHub releases.
2. **Navigate** to your SAC tenant, then go to the **Stories** page and click on **Custom Widget** tab.
3. **Upload**: Click on the `+` icon and select the downloaded file.
4. 🎉 **Done!** You can now use the widget in your application.

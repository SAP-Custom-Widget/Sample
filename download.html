Installation Instructions ​

  1. Download the widget .json file using the button above.
  2. Open your SAP Analytics Cloud tenant.
  3. Navigate to Custom Widgets in the left menu.
  4. Click the + (Add) button.
  5. Upload the .json file you just downloaded.
